## Background
- folder contains project for mediawiki site for an private server game (Final Fantasy 11 - FF11)
- project is a series of tools each published as a Special Page
- each special page provides a tool for the user
- tools are designed to give the user an opportunity to build and design their characters outside the game to theorycraft their play style before playing the game
- automatons are pets that fight along side the user's character   
  
## Description
